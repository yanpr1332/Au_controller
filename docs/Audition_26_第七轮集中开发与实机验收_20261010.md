## 一、波形级编辑和 PCM 定量交付

新增模块：controller_modules/waveform_workbench.py

公开方法：
- edit_wav_timeline：以整数采样帧为定位单位，执行 Cut/Delete、从原始输入 Copy/Insert、插入静音、区段静音、局部增益和 Fade In/Out。
- export_fft_spectrum：使用 SciPy Welch 方法分析频率—功率分布，输出 machine-readable JSON，包括采样率、FFT窗口、频点数组、声谱功率和主频。

PCM16 量化提供 3 种输出：
- 无抖动，标准舍入；
- 可复现 TPDF（三角概率密度）抖动；
- TPDF + 简单的一阶误差反馈噪声整形（不是 Audition 专有的 Noise Shaping 预设）。

每次使用强类型参数、边界、无覆写、限时长、输出回读及原始输入 SHA256。真实验收产生 3 份 117600 帧 PCM16，另以原始 Float32 WAV 产生 2 份 192000 帧 PCM16；三种模式互有不同 SHA256，输入不变。
FFT 主频实际读取约 445.3 Hz（4096 点窗分辨率）。

证据：
tests/receipts/phase07_waveform_timeline_acceptance.json
tests/receipts/phase07_float_to_pcm16.json

## 二、原生 SESX 剪辑分割

新增模块：controller_modules/native_clip_split.py
方法：split_native_qa_clip

只能操作位于 tests 目录、前缀 ACCEPT_AU_ 的合成测试 SESX，不覆盖既有工程：
- 将一个既有 clip 在指定 offset_samples 切开为两个 Native audioClip；
- 保持同一个 fileID，新的片段分配全局唯一 clip ID；
- 同时调整时间轴 startPoint/endPoint、源媒体 sourceInPoint/sourceOutPoint 与 split 处 Fade；
- 限制未 loop 的、时间和来源时长一致的 QA clip；
- 所有文件和 XML 在写入前验证。

实机：将 115200 帧原始 Clip 分割为 48000 + 67200。Audition 26 重新打开后确实识别为 2 个 Clip，并原生 Mixdown 输出 139200 帧、48 kHz WAV。
与拆分前原生 Mixdown 比较，最大绝对波形差约 4.8×10⁻¹⁹（该特定测试素材与处理条件下）。

证据：
tests/receipts/phase07_native_split_acceptance.json
tests/receipts/phase07_qa_closed.json

## 三、原生媒体导入和轨道控制

对旧 AU014（MP3 打开）与 AU015（FLAC 打开）执行实际 Audition openDocument：
- MP3、FLAC 分别成为 Native WaveDocument；
- 原生回读采样率 48000 和各自时长（115200、48000 samples）；

## 四、声道分离/重组及声明式工作流

新增模块：controller_modules/channel_tools.py：
- split_stereo_to_mono
- combine_mono_to_stereo

对 48000 Hz / 192000 帧 Float32 双声道 WAV，独立导出左右声道并重新拼接回 2 声道。
实际重组音频逐样本与源相同（最大绝对误差 = 0）；媒体来源不变，独立文件带 SHA256 与解码回读。

生产 Pipeline controller_modules/production_jobs.py 现增加：
- wave_edit：串接样本级编辑、PCM16 抖动/整形；
- fft：把频率谱 JSON 作为后续可追溯产物。

实际验收 4 步：
样本级删除和 Fade + PCM16量化 → FFT频谱 → 两遍 LUFS 母带 → 播客 QC。
整组先暂存、全部校验后发布、附 SHA256 依赖清单，输入 SHA256 保持不变。异常时按现有机制清理本次暂存结果，不能声称达到断电事务持久性。
